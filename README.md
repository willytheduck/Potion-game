Hello again, This is the fourth game I've made so far

This game is where u mix potion for witches/dummies(practice), also this time I made the pixel art myself from tutorials and references using aseprite. This is a really fun project to draw I'm very satisfied with the outcome. I plan to make the game like bartender game but my time isn't enough so i did the second best thing. 
In this game there is:
1. Normal where there is only 1 potion for 1 witch 
2. Hard where there is 2-3 potion for 1 witch and a boss is present
3. Practice where the is dummy and u can find recipes there is only 6 recipes in total
4. There is also hint (cost coins and doesnt cost coin)
5. There is also mute button by pressing m and recipes by pressing b
6. Streak, highscore, and coins for hints

How to play:
1. Press either 1 or 2 (1 for normal, 2 for hard, 3 for practice)
2. H for hint (I recommend doing practice first then the normal or hard mode)
3. B for recipes (not unlocked and unlocked)
4. Good Luck!
